# System Architecture

The Production App is a monolithic Node.js and Express application that simulates a microservices architecture. It contains three primary logical services:

1. **User Service**: Manages user accounts and profiles.
2. **Payment Service**: Processes transactions and interacts with the payment gateway and database.
3. **Order Service**: Manages customer orders.

## Tech Stack
- **Runtime**: Node.js
- **Framework**: Express.js
- **Database**: PostgreSQL (Simulated)
